# Models

This folder stores the active trained ranking model and the local SBERT embedding model.

## Active Files

```text
final_resume_ranker.joblib
final_resume_ranker_metadata.txt
all-MiniLM-L6-v2/
```

## final_resume_ranker.joblib

The final saved ML artifact used by the backend ranking service.

It contains:

- selected model name: XGBoost
- fitted XGBoost model
- feature names
- training threshold
- dataset name
- model comparison metrics

## all-MiniLM-L6-v2

Local SBERT model used for semantic similarity. Keeping it locally helps the project run without downloading the model every time.
